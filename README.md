# MemorySprout Legal (public)

Public Privacy Policy and Terms of Use HTML only.
This repository intentionally contains **no** app source code.

Regenerate from the private MemorySprout repo:

```bash
python3 scripts/generate-legal-html.py
./scripts/sync-legal-public-repo.sh /path/to/this/repo
```

GitHub Pages should serve the repo root. URLs:

- `./legal/privacy.html` (EN | 中文 toggle)
- `./legal/terms.html` (EN | 中文 toggle)
- App embed: add `?embed=1&lang=en` or `lang=zh-Hans`
