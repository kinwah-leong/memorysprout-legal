2 处理的信息

照片与 Memory 内容。 我们处理您在 Create / Sprout 中选择并上传的照片、用于分析的压缩图、生成的 Story 与成片、您的编辑结果及相关 Memory 记录。照片可能包含人脸、他人、文字、位置或敏感信息。

照片元数据。 本机可能读取所选照片的 EXIF / GPS，用于推断拍摄时间，并在需要时生成大致地点标签。原始 GPS 坐标不会入库。 我们可能仅保存“该照片是否含有位置元数据”的布尔标志（`contains_location_metadata`）。云端保存 Memory 资产不要求保留多余 EXIF。

账户与认证。 您可以以访客 / 匿名会话使用核心功能。若使用 通过 Apple 登录 或 Google 登录，我们会接收您授权范围内的账户信息，例如提供方用户标识，以及您选择共享的姓名或电子邮箱。Apple 可能提供“隐藏我的邮箱”转发地址。我们处理维持会话所需的认证信息。我们不会获取您的 Apple ID 或 Google 密码。登录本身不授权我们访问 Apple 相册、Google 相册、Gmail、通讯录或其他无关服务。

Google 登录使用标准身份范围（通常为 OpenID / email / profile），不申请 Google Photos 或 Drive 权限。

使用统计。 我们使用 Google Analytics for Firebase 了解产品使用情况（例如交互事件、会话、应用实例标识、设备型号、系统、版本、语言及大致地区）。应用内已启用 Analytics，目前没有单独的应用内统计开关；您可使用 iOS 系统提供的相关隐私控制。

崩溃与诊断。 我们使用 Firebase Crashlytics 处理崩溃报告、堆栈、应用/设备信息与安装标识。还可能向后端发送有限、非密钥的诊断事件（例如稳定错误码与耗时）以便排查联调问题。我们不会故意将密码、身份令牌或完整邮箱写入诊断载荷。

运行日志。 后台与基础设施服务商可能按配置处理 IP、时间戳、状态码等请求元数据。

支持。 您联系我们时，我们处理您提供的联系方式与消息内容以便回复。

3 处理目的及法律依据

我们使用相关信息以：

  • 提供 Memory 创建、Story / 成片生成、编辑、保存与分享；
  • 认证用户、维持访客与登录会话，并在登录后支持跨设备同步；
  • 在适用情况下将访客 Memory 归属到登录账户；
  • 改善稳定性并了解产品使用；
  • 防止滥用并履行法律义务。

如适用欧洲经济区或英国数据保护法律，处理依据包括：为提供您请求的服务而履行合同；依法需同意时的同意；在权衡您的权益后基于合法利益开展适度的安全、防滥用与必要诊断；以及履行法律义务。

您选择照片并开始 Create / Sprout，即表示请求将该照片经我们的云端流程处理（含下文第三方 AI）。若您不希望照片进入云端处理，请勿提交 Create / Sprout。

4 云端 AI 处理

创建 Memory 时，所选照片（通常为压缩分析图）及相关提示/上下文会经 托管在 Supabase 上的 MemorySprout Edge Functions，再发送至当前环境配置的一个或多个 AI 服务商。视配置可能包括：

  • DeepSeek（分析）；
  • OpenRouter（分析及/或生图；可能路由至如 Google Gemini 图像模型等）；
  • 阿里云 DashScope / 通义千问（在启用时用于分析及/或生图）。

输入可包含图像字节及 Story 分析或明信片生成所需的文本上下文。输出包括 Story 文本、结构化分析字段，以及与您的 Memory 关联的生成图像资源。

我们不会用您的照片或 Story 训练自有 AI 模型。第三方服务商按自身条款及我们的 API 配置处理输入以返回结果；可能因滥用监测或按其政策短暂留存。我们不会出售您的照片用于广告。

AI 生成的 Story 与成片属于创作性解释，可能不准确，不能作为关于人物身份、健康、情绪或经历的可靠事实陈述。请仅上传您有权使用且有权分享的照片。除非已取得必要授权，请避免提交敏感个人信息或可识别儿童身份的照片。

停止创建新的 Memory 即可停止后续 AI 处理。已处理内容的删除见下文。

5 设备权限及您的选择

照片。 通过系统照片选择器选取；我们仅处理您为 Create / Sprout 等相关流程选择的照片。允许访问设备照片本身，不等于已同意上传至云端 AI。

位置。 若所选照片缺少 EXIF 坐标，应用可能请求“使用期间的位置”以解析大致地点用于展示。坐标用于本机解析，不会以原始 GPS 形式入库。

导出与分享。 保存或分享 Memory 使用您发起的 iOS 分享 / 相册流程，目的地规则由其自行适用。

登录管理。 个人中心 → 账户 → 登录方式，可管理 Apple / Google 关联。退出登录、撤销提供方授权、删除应用、清除个人数据与注销账户是不同操作。

6 信息披露及服务商

我们会向协助提供服务的服务商披露信息，包括：

  • Supabase - 认证、Postgres、对象存储（上传照片与生成资产）及 Edge Functions；
  • Apple - 通过 Apple 登录；
  • Google - Google 登录、Firebase Analytics、Firebase Crashlytics；
  • 第 4 节所列 AI 服务商。

Google 隐私说明：https://policies.google.com/privacy

Firebase 隐私：https://firebase.google.com/support/privacy

Supabase 隐私：https://supabase.com/privacy

对于代表我们处理信息的服务商，我们要求其采取与本政策及适用法律相符的合同与安全保护。

我们可能在法律要求、保护合法权益或安全所必需时披露信息；应用或相关业务转让时，也可能在适用保障下转移信息。您主动分享或导出的信息由您选择的目的地接收。

广告、出售与追踪。 我们不出售个人信息。我们不会将 Memory 照片用于跨情境行为广告。应用不以基于 IDFA 的广告追踪为核心配置。Firebase 产品分析用于改进 MemorySprout，而非售卖广告。

7 存储及保存期限

账户与 Memory 数据的主要托管与存储由 Supabase（数据库与对象存储）提供。处理地区取决于我们的 Supabase 项目配置及 AI 服务商所在地区。

照片、成片、Story 与账户记录的保存期限取决于：

  • 您是否继续使用账户；
  • 您是否删除单条 Memory 或清除个人数据；
  • 您是否注销账户；
  • 法律、安全或备份要求。

我们不会对 Memory 资产适用固定的“满 90 天自动删除”规则。除非您请求删除、账户已注销，或法律/安全要求，我们不会随意删除作为您个人数据资产保存的照片或生成内容。

相关系统大致情况：

  • Firebase Crashlytics： Google 当前说明约为 90 天后开始从线上及备份系统删除崩溃堆栈及关联标识。
  • Analytics： 按 Firebase 项目配置留存。
  • 运行日志与备份： 按安全与恢复需要轮转；主删除后可能短暂残留。
  • AI 服务商副本： 受各服务商 API 及滥用监测留存规则约束。

仅保存在您设备或已分享给他人的内容，不会因我们删除己方副本而自动消失。

8 账号删除和个人数据删除

您可在应用内管理数据：

  • 清除个人数据： 个人中心 → 账户 → 清除个人数据（按实现删除与当前账户路径关联的上传 / Memory 数据）。
  • 注销账户： 个人中心 → 账户 → 注销账户（确认后永久注销）。

也可联系 【待填写：隐私联系邮箱】 寻求协助。

账户注销后，我们将在合理期限内删除或匿名化账户相关数据，包括认证信息、上传照片、生成成片、Story 及相关历史，但仍受以下约束：

  • 法律义务；
  • 安全与防欺诈；
  • 备份轮转周期；
  • 服务商删除时限。

注销账户不会自动删除：

  • 已保存在设备本地的文件；
  • 您已分享给他人的内容；
  • 您选择的第三方目的地中的副本；
  • 您的 Apple 或 Google 账户本身。

9 您的隐私权利

根据所在地及适用法律，您可能享有查阅、更正、删除、限制或反对处理、数据可携带、撤回同意，以及向监管机构投诉等权利。若涉及出售/共享/定向广告相关权利，第 6 节说明了我们实际做什么与不做什么。

请将请求发送至 【待填写：隐私联系邮箱】。我们会进行适度核验，在法定期限内回应，并说明依法拒绝的理由。我们不会因您行使隐私权而实施违法歧视。

对于加州居民，在 CCPA 适用时：收集类别、来源、目的、保存标准及接收方见第 2-7 节。我们不出售个人信息，也不为跨情境行为广告共享个人信息（按通常定义）。

10 国际数据传输

您的信息可能在您所在国家或地区之外处理，包括 Supabase、Google、Apple 及 AI 服务商使用的地区。不同国家可能适用不同隐私法律。如有法律要求，我们会采用适当的转移保障（例如充分性认定或标准合同条款），并在必要时采取补充措施。更多信息请联系 【待填写：隐私联系邮箱】。

11 儿童及年龄要求

MemorySprout 面向年满 13 岁（或您所在国家要求的更高年龄）的用户，不以低于该年龄的儿童为目标。对于低于适用最低年龄的用户，我们不会在缺乏有效法律依据及必要监护人授权的情况下，明知而收集其个人信息。如您认为儿童不当提供了信息，请联系 【待填写：隐私联系邮箱】。

照片中是否包含儿童，与应用使用者的年龄是不同问题；所需授权仍然适用。

12 安全及政策更新

我们根据所处理信息及相关风险采取合理保护措施，包括 HTTPS 传输加密、后台访问控制，以及密钥与客户端分离。任何系统都无法保证绝对安全。

数据处理方式或法律义务变化时，我们会更新本政策、公布修订日期，并对重大变化提供通知；如依法需要，将重新取得同意。发布新版政策本身不代表您已同意将信息用于新的目的。
